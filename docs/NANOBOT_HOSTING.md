# APP 内 Nanobot 体验版

入口：AI 助手 → Nanobot 体验版。原版助手继续使用 LangGraph；两者不共享会话，
Nanobot 请求失败不会回退到原助手或固定回复。原银行首页与业务入口没有合并进聊天。

## 实际调用链

PWA 登录会话 → 银行 Nanobot API → 私有 Python supervisor → 独立 Nanobot 子进程
→ 银行 MCP → 银行核心。工具记录由 `mcp_invocations` 提供，回复由真实模型生成。
用户打开的授权单据由银行 API 重新读取，不解析模型生成的链接或金额来执行付款。

首次连接需要勾选数据使用/权限说明，并通过银行密码复核。密码只到银行 API，不传给
Python 服务或模型。银行保存 30 天连接授权；每次运行生成最多四分钟有效的 MCP 令牌，
只保存哈希，明文经私有服务传给对应子进程，运行结束即撤销。令牌不能执行最终付款。

数据库保存运行状态与公开对话。每个连接授权、每个会话使用不同工作目录，跨运行保留
Nanobot 会话文件，因此刷新 APP 和下一次启动独立进程仍可延续对话。断开后立即撤销
银行访问和在途运行状态，历史记录保留供审计；再次连接使用新目录，不继承旧连接记忆。

## 部署

1. 备份现有数据库，在原有迁移上执行 `007_nanobot_preview.sql`。没有清空/重建旧表。
2. 在服务器私有 `deploy/.env.production` 配置独立随机 `NANOBOT_SERVICE_TOKEN`，
   至少 32 字符；`NANOBOT_ALLOWED_USERS` 填允许体验的客户 UUID 或已注册手机号。
   不设置名单时拒绝使用，不允许浏览器自行指定租户或放宽名单。
   可用 `python3 deploy/configure_nanobot.py --env-file deploy/.env.production` 在服务器
   生成内部凭据，不输出密钥值；`--allow-users` 可设置精确体验名单。
3. 模型沿用平台 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`，用户无需配置模型 Key。
4. 启动：

```sh
docker compose --env-file deploy/.env.production -f deploy/compose.production.yml \
  --profile nanobot up -d --build app nanobot
```

Python 服务不映射公网端口，使用独立出网网络和银行内部网络；非 root、只读根文件系统、
删除 Linux capabilities、禁止提权。上限 768 MiB / 1 CPU / 96 PID，全局最多两次运行，
每用户同时一次、24 小时最多 50 次；连接验证每 15 分钟最多五次。

浏览器提交后拿到运行编号并轮询银行数据库，不维持长时间 HTTP 响应。重复请求编号不
重复执行模型；服务超时/重启后不自动重放，过期运行显示失败并撤销令牌。可能已生成的
草稿仍在银行记录中，不会因此自动付款。回滚可切回原版助手并停用 nanobot profile；
无需删除迁移或历史数据。

## 验证与已知边界

- 本地独立数据库、真实 DeepSeek：17 项托管链路断言通过，包括两个用户并发、
  跨用户不可见、请求幂等、真实转账草稿、跨进程上下文续接、撤销后禁止运行。
- Python 测试共 11 项；其中一次真实 MCP 撤销生命周期测试需显式启用数据库测试。
- 原项目 29 项测试通过。模型回复的成功状态表示对话运行完成，不表示资金已转出。
- Playwright 在 390×844 手机尺寸下验证：打开原版/Nanobot 切换入口、恢复历史对话、
  从真实工具记录打开 1 元转账单、银行弹窗确认后单据刷新为成功。
- 本轮没有连接真实 IM；此入口只在 APP 内试用，不宣称六类赛题业务全覆盖。
- **子进程隔离不是每租户独立容器。** 子进程使用同一容器 UID，工作目录路径和工具凭据
  由可信 supervisor 分配，模型没有 shell/文件/网络通用工具。仍不能抵抗宿主/依赖漏洞
  或任意代码执行后的跨目录访问。因此仅定向体验，不作为开放多租户安全认证。
- 连接撤销不会立即杀掉正在生成文字的模型调用，但后续银行请求被拒绝，回调不能覆盖
  已取消运行。服务容量最多等待该运行超时后释放。
- 对话明文保存在受限服务器与数据库，尚无自助删除/保留期限作业；禁止输入密码或密钥。
- 工具调用后的语言仍可能失准，银行单据和账本才是业务结果依据。

复现托管评测见 `integrations/nanobot/evaluate_hosted.py`。它只接受本地隔离测试流程，
合成手机号和测试密码不能用于线上账户；测试模型配置可从已获授权的服务器在内存读取。
